# 📰 BR NOTÍCIAS - Portal de Notícias & CMS (v2.0)

> **Trabalho Front-End Frameworks & Desenvolvimento de Aplicações para Internet**

Portal de notícias dinâmico e moderno desenvolvido com HTML5, CSS3 e JavaScript Vanilla. Apresenta identidade visual em tons de verde, filtro por categorias, busca em tempo real, área do leitor (login/cadastro) e painel administrativo (CMS) completo com CRUD e persistência via `localStorage`.

### 🚀 Funcionalidades
* 🟢 **Design Verde e Responsivo**: Layout limpo, moderno e otimizado para todos os ecrãs.
* 🔍 **Busca e Categorias**: Pesquisa de matérias por texto e filtro rápido (*Esporte, Lazer, Livros, Tecnologia, Economia, Educação, Região*).
* ⚙️ **Painel CMS Admin (CRUD)**: Publicação, edição e exclusão de notícias em tempo real.
* 💾 **Armazenamento Local**: Notícias salvas diretamente no `localStorage` do navegador.
* 🔐 **Área do Leitor**: Páginas interativas de Login e Cadastro.
